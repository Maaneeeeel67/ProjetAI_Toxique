# 🛡️ AI Toxicity Detection

> Détection automatique de commentaires toxiques via NLP et modèles de Machine Learning / Deep Learning.

## 🎯 Objectif
Détecter automatiquement la toxicité dans des commentaires textuels (insultes, haine, harcèlement) à l'aide de techniques de NLP modernes.

## 📁 Structure du projet
- `src/api.py` — API de prédiction
- `src/app_streamlit.py` — Dashboard interactif
- `src/eda.py` — Analyse exploratoire
- `src/interface.py` — Interface de prédiction
- `src/social_sim.py` — Simulation réseaux sociaux
- `src/train_baseline.py` — Entraînement baseline ML
- `src/train_transformer.py` — Entraînement Transformer
